# data.md 格式

~~~markdown
# 02 订单：数据结构

## 复用与新增

| 概念 | 处理 | 实体 | 说明 |
|---|---|---|---|
| 顾客 | 复用 | User（01 块） | 原样引用 |
| 商品库存 | 扩展 | Product（现有代码） | 加 `reserved` 字段记录已下单未发货的数量 |
| 订单 | 新增 | Order | 已有实体里没有表示一次结算的 |

## 实体

### Order 订单

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| id | ID | 是 | |
| user_id | → User | 是 | 下单人 |
| status | 枚举 | 是 | 见状态机 |
| total | 金额 | 是 | 应付总额 |
| cancel_reason | 枚举 | 否 | 取消时必填，选项见 decisions.md |
| created_at | 时间 | 是 | |

- 关系：Order 1—n OrderItem；Order n—1 User
- 唯一性：（user_id, client_token）唯一，防重复提交
- 删除：不物理删除，取消用状态表示；User 注销时订单保留
- 状态机：
  - 待支付 → 已支付：支付成功
  - 待支付 → 已取消：顾客取消，或 30 分钟未支付
  - 已支付 → 已发货 → 已完成
- 不变量：total 等于各 OrderItem 小计之和

## 表结构

每张新表或改动的表一段：表名、列、数据库类型、约束、索引。扩展已有表只写新增和改动的列。

## 接口契约

每个接口一段：方法和路径、请求字段、响应字段、错误情况。字段名和上面的实体一致。
~~~

## 规则

- 「复用与新增」覆盖本块用到的每个概念。
- 每个实体都写：字段表、关系、唯一性、删除规则。有状态的写状态机，每条流转写触发条件；有跨字段约束的写不变量。
- 字段表里的类型写业务层面的（ID、金额、枚举、时间、→ 引用的实体），数据库类型写在「表结构」。
- 引用其它块的实体时只写引用，它的字段定义留在所在块的 data.md。
- 实体名、字段名和 GLOSSARY.md 一致。
- 项目有数据库时写「表结构」，前后端分离或对外提供接口时写「接口契约」；没有的节省略。
